# Carnet de recettes

Application web installable (PWA), utilisable hors ligne. Le code est ici ; les données (recettes et journal) sont dans un dépôt **privé** séparé, lu et écrit via l'API GitHub avec un jeton limité à ce dépôt.

- Publier : Settings → Pages → Deploy from a branch → `main` / `(root)`.
- Installer sur Android : ouvrir la page dans Chrome → menu ⋮ → « Ajouter à l'écran d'accueil » / « Installer l'application ».
- Configurer : ⚙ → compte, dépôt de données, jeton (Contents : Read and write sur le seul dépôt de données).
